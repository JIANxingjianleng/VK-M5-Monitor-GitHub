# VK M5 Monitor v24.0

发布日期：2026-11-14

## 新增

- **蓝牙 DPI 读写**：按 Valkyrie Driver 的 BLE HID 协议实现 `0x55 + 0x90/0x10`，先读 `0x82` 当前 profile，再读写对应层；蓝牙模式下 DPI 页可正常切换档位。
- **蓝牙电量优先 `0x77` 查询**：直接问设备要电量，不再优先依赖 Windows GATT 缓存。
- **三模自动识别**：2.4G / 蓝牙 / 有线，按实际连接切换，不提供手动改连接方式。

## 改进

- 2.4G 电量走 HID `F7` 特征报告，约 5 秒刷新；界面标注「HID 直读」。
- 蓝牙 GATT 回退时标注「蓝牙缓存」，不把缓存值伪装成实时值。
- 有线显示「充电中」+ 闪电电池 + 1.2 秒呼吸，不再写死 100%。
- 「立即刷新」会作废电量、DPI、链路缓存并立即重读。
- 托盘图标按模式显示绿/蓝/琥珀色顶部状态条，电量数字按高/中/低变色。
- 简洁圆盘、右键菜单、DPI 菜单项同步状态。

## 兼容

- VK M5：VID `0x374A`，有线 `0xA321`、2.4G `0xA322`、蓝牙 `0xA323`。
- A955：VID `0x260D` 内置配置（电量分档 25/50/75/100，DPI 400/800/1600/3200/6400）。
- 其他设备：通过 `%APPDATA%\VK_M5\devices.json` 增加配置。

## 已知问题

- 蓝牙 DPI 写入约 0.5–1 秒；Valkyrie Driver 同时运行时可能抢占 HID 通道。
- 蓝牙必须先由 Windows 配对，程序不会静默配对。
- 2.4G 鼠标休眠时沿用上次读数，最长 30 分钟。
- 厂商协议非公开，固件升级后可能失效。
